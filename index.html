How it works

  1. One screen, every board. Hackathons, micro-bounties and paid-per-view campaigns are stitched together from sources that were never designed to talk to each other — Devpost, Kaggle, Taskmarket, Content Rewards.
  2. Verified, not scraped blindly. Each entry carries the date it was last verified live and a note on who can join, so a beginner in Indonesia never wastes a week on a US-only contest.
  3. Live where possible. The app tries the public Taskmarket API on load and merges fresh tasks in. When the API is down it falls back to the bundled snapshot and says so plainly.

Snapshot data verified 16 Nov 2026. Deadlines and prizes change — always re-check the official page before entering. No account needed to browse. Gig Radar stores nothing about you; filter preferences stay in your browser only.
